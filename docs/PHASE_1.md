# Phase 1: Android and Root Runtime Bootstrap

## Scope

Phase 1 establishes a buildable Android application and verifies the minimum runtime assumptions needed for later APK extraction.

Implemented:

- Kotlin and Jetpack Compose Android application.
- Read-only `su` discovery.
- Root authorization check using `su -c id`.
- KernelSU detection from version output and the fixed `/data/adb/ksu` or `/data/adb/ksud` marker.
- Process timeout and error handling.
- Unit-tested parsing of UID, GID, SELinux context, and provider evidence.
- GitHub Actions lint, unit tests, debug build, SHA-256 generation, and APK artifact upload.

## Security boundary

The first phase does not:

- Extract or modify another application's APK.
- Read another application's private data.
- Execute code from a target APK or SO file.
- Accept arbitrary shell commands.
- Send device data to an external API.

All shell commands are fixed probes defined by application code.

## Device test checklist

1. Install the debug APK generated by GitHub Actions.
2. Open AutoCrackApp.
3. Allow the KernelSU root request.
4. Confirm the screen reports UID `0` and provider `KernelSU`.
5. Deny permission and run the probe again to verify the denied state.
6. Record device model, Android version, KernelSU version, and any diagnostic shown by the app.
